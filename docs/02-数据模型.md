# 数据模型

## SQLite 表结构

### providers 表

存储 Provider 基本信息。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | TEXT | PRIMARY KEY | Provider 唯一标识，如 "openai" |
| name | TEXT | NOT NULL | 显示名称 |
| enabled | INTEGER | NOT NULL DEFAULT 1 | 是否启用（0/1） |
| is_built_in | INTEGER | NOT NULL DEFAULT 0 | 是否为内置 Provider |
| base_url | TEXT | | API 基础地址 |
| api_key | TEXT | | API Key（AES 加密存储） |
| api_type | TEXT | | API 类型枚举 |
| headers | TEXT | | JSON 格式的自定义请求头 |
| auth_header | INTEGER | | 是否使用 Authorization Header（0/1） |
| auth | TEXT | | 认证方式："apiKey" / "none" |
| discovery | TEXT | | JSON 格式的自动发现配置 |
| created_at | TEXT | | ISO 8601 时间戳 |
| updated_at | TEXT | | ISO 8601 时间戳 |

### provider_models 表

存储自定义模型定义。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | TEXT | PRIMARY KEY | 模型唯一标识 |
| provider_id | TEXT | NOT NULL FK | 所属 Provider |
| model_id | TEXT | NOT NULL | 模型 ID，如 "gpt-4o" |
| name | TEXT | NOT NULL | 显示名称 |
| api_type | TEXT | | 覆盖的 API 类型 |
| reasoning | INTEGER | | 是否支持推理（0/1） |
| input_types | TEXT | | JSON ["text", "image"] |
| cost | TEXT | | JSON 成本定义 |
| context_window | INTEGER | | 上下文窗口大小 |
| max_tokens | INTEGER | | 最大 Token 数 |
| headers | TEXT | | JSON 模型级请求头 |
| compat | TEXT | | JSON 兼容性配置 |

### model_overrides 表

存储对内置模型的覆盖配置。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | |
| provider_id | TEXT | NOT NULL FK | |
| model_id | TEXT | NOT NULL | 被覆盖的模型 ID |
| override_data | TEXT | NOT NULL | JSON 覆盖数据 |

### app_settings 表

全局设置（单条记录）。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY CHECK(id=1) | 固定为 1 |
| default_provider | TEXT | | 默认 Provider |
| default_model | TEXT | | 默认模型 |
| default_thinking_level | TEXT | | thinking 级别 |
| hide_thinking_block | INTEGER | | 是否隐藏 thinking 块 |
| thinking_budgets | TEXT | | JSON 各级别预算 |
| model_roles | TEXT | | JSON 角色配置 |
| retry_fallback_chains | TEXT | | JSON 回退链 |
| updated_at | TEXT | | |

### sync_config 表

WebDAV 同步配置（单条记录）。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY CHECK(id=1) | 固定为 1 |
| enabled | INTEGER | NOT NULL DEFAULT 0 | 是否启用同步 |
| server_url | TEXT | | WebDAV 服务器地址 |
| username | TEXT | | 用户名 |
| password | TEXT | | 密码（AES 加密） |
| remote_path | TEXT | DEFAULT "/omp-switch.db" | 远程路径 |
| last_sync_at | TEXT | | 最后同步时间 |
| last_sync_status | TEXT | | "success" / "conflict" / "error" |
| last_error | TEXT | | 错误信息 |

### sync_changelog 表

变更日志，用于冲突检测。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | |
| table_name | TEXT | NOT NULL | 变更表名 |
| record_id | TEXT | NOT NULL | 变更记录 ID |
| action | TEXT | NOT NULL | insert / update / delete |
| changed_at | TEXT | NOT NULL | 变更时间 |
| device_id | TEXT | NOT NULL | 设备唯一标识 |

## Rust 模型定义

```rust
// models/provider.rs
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ProviderConfig {
    pub id: String,
    pub name: String,
    pub enabled: bool,
    pub is_built_in: bool,
    pub base_url: Option<String>,
    pub api_key: Option<String>,
    pub api_type: Option<String>,
    pub headers: Option<HashMap<String, String>>,
    pub auth_header: Option<bool>,
    pub auth: Option<String>,
    pub discovery: Option<DiscoveryConfig>,
    pub model_overrides: Option<HashMap<String, ModelOverride>>,
    pub models: Option<Vec<ModelDefinition>>,
    pub created_at: Option<String>,
    pub updated_at: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ModelDefinition {
    pub id: String,
    pub name: String,
    pub api_type: Option<String>,
    pub reasoning: bool,
    pub input_types: Vec<String>,
    pub cost: ModelCost,
    pub context_window: i64,
    pub max_tokens: i64,
    pub headers: Option<HashMap<String, String>>,
    pub compat: Option<ModelCompat>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ModelCost {
    pub input: f64,
    pub output: f64,
    pub cache_read: f64,
    pub cache_write: f64,
}
```

## TypeScript 类型定义

```typescript
// types/provider.ts
export interface ProviderConfig {
  id: string;
  name: string;
  enabled: boolean;
  isBuiltIn: boolean;
  baseUrl?: string;
  apiKey?: string;
  api?: ApiType;
  headers?: Record<string, string>;
  authHeader?: boolean;
  auth?: "apiKey" | "none";
  discovery?: { type: "ollama" | "lmstudio" };
  modelOverrides?: Record<string, ModelOverride>;
  models?: ModelDefinition[];
  createdAt?: string;
  updatedAt?: string;
}

export type ApiType =
  | "openai-completions"
  | "openai-responses"
  | "openai-codex-responses"
  | "azure-openai-responses"
  | "anthropic-messages"
  | "google-generative-ai"
  | "google-vertex";

export interface ModelDefinition {
  id: string;
  name: string;
  api?: ApiType;
  reasoning: boolean;
  input: ("text" | "image")[];
  cost: {
    input: number;
    output: number;
    cacheRead: number;
    cacheWrite: number;
  };
  contextWindow: number;
  maxTokens: number;
  headers?: Record<string, string>;
  compat?: ModelCompat;
}
```
