# 跨平台适配

## 支持平台

| 平台 | 最低版本 | 构建目标 |
|------|----------|----------|
| macOS | 11+ (Big Sur) | `x86_64-apple-darwin`, `aarch64-apple-darwin` |
| Windows | 10+ | `x86_64-pc-windows-msvc` |
| Linux | Ubuntu 20.04+ / Fedora 35+ | `x86_64-unknown-linux-gnu` |

## 配置目录

使用 Tauri `app_local_data_dir()` 获取平台适配路径：

| 平台 | omp-switch 数据目录 | omp 配置目录 |
|------|---------------------|--------------|
| macOS | `~/Library/Application Support/com.omp-switch/` | `~/.omp/agent/` |
| Windows | `%LOCALAPPDATA%/omp-switch/` | `~/.omp/agent/` |
| Linux | `~/.config/omp-switch/` | `~/.omp/agent/` |

## 跨平台注意事项

### 路径处理

```rust
// utils/fs.rs
use std::path::PathBuf;

pub fn get_omp_agent_dir() -> PathBuf {
    let home = dirs::home_dir().expect("无法获取用户主目录");
    home.join(".omp").join("agent")
}

pub fn get_switch_data_dir() -> PathBuf {
    // 使用 Tauri 的 app_local_data_dir
    // 在 Rust 中通过 tauri::Manager::path().app_local_data_dir() 获取
    PathBuf::new() // 实际由 Tauri 注入
}

/// 原子写入：先写临时文件，再重命名
pub fn atomic_write(path: &PathBuf, content: &str) -> std::io::Result<()> {
    let dir = path.parent().unwrap();
    let mut temp = tempfile::NamedTempFile::new_in(dir)?;
    std::io::Write::write_all(&mut temp, content.as_bytes())?;
    temp.persist(path)?;
    Ok(())
}
```

### 文件监听

```rust
// services/file_watcher.rs
use notify::{Config, Event, RecommendedWatcher, RecursiveMode, Watcher};

pub fn start_watching(path: &PathBuf, callback: impl Fn(Event)) -> Result<RecommendedWatcher> {
    let mut watcher = RecommendedWatcher::new(
        move |res: Result<Event, _>| {
            if let Ok(event) = res {
                callback(event);
            }
        },
        Config::default(),
    )?;
    watcher.watch(path, RecursiveMode::Recursive)?;
    Ok(watcher)
}
```

- macOS：使用 FSEvents
- Windows：使用 ReadDirectoryChangesW
- Linux：使用 inotify

### 系统托盘

```rust
// main.rs
use tauri::tray::{TrayIconBuilder, TrayIconEvent};

fn setup_tray(app: &mut tauri::App) {
    let tray = TrayIconBuilder::new()
        .icon(app.default_window_icon().unwrap().clone())
        .menu(&tauri::menu::Menu::new(app).unwrap())
        .on_menu_event(|app, event| {
            match event.id.as_ref() {
                "show" => {
                    if let Some(window) = app.get_webview_window("main") {
                        window.show().unwrap();
                        window.set_focus().unwrap();
                    }
                }
                "quit" => {
                    app.exit(0);
                }
                _ => {}
            }
        })
        .build(app)
        .unwrap();
}
```

## 打包脚本

```bash
# macOS
npm run tauri build -- --target universal-apple-darwin

# Windows (交叉编译需配置)
npm run tauri build -- --target x86_64-pc-windows-msvc

# Linux
npm run tauri build -- --target x86_64-unknown-linux-gnu
```

## CI/CD 建议

使用 GitHub Actions 矩阵构建：

```yaml
strategy:
  matrix:
    include:
      - os: macos-latest
        target: universal-apple-darwin
      - os: windows-latest
        target: x86_64-pc-windows-msvc
      - os: ubuntu-latest
        target: x86_64-unknown-linux-gnu
```
