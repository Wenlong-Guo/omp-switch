# 后端设计

## 分层架构

后端采用严格分层：Commands → Services → DAO → Database。

```
┌─────────────────────────────────────────┐
│  Commands (IPC 暴露层)                    │
│  - 接收前端 invoke 调用                    │
│  - 参数校验、序列化/反序列化               │
│  - 调用 Service 层，返回结果              │
├─────────────────────────────────────────┤
│  Services (业务逻辑层)                    │
│  - 业务规则校验                           │
│  - 多 DAO 协调、事务管理                  │
│  - 文件读写、WebDAV 同步                  │
├─────────────────────────────────────────┤
│  DAO (数据访问层)                         │
│  - 纯 SQL 操作                           │
│  - 数据映射 Rust 结构体                   │
│  - 无业务逻辑                            │
├─────────────────────────────────────────┤
│  Database (SQLite)                        │
│  - rusqlite 连接                         │
│  - 迁移脚本管理                          │
└─────────────────────────────────────────┘
```

## Commands 模块

### provider.rs

| 命令 | 签名 | 功能 |
|------|------|------|
| `get_providers` | `() -> Vec<ProviderConfig>` | 获取所有 Provider |
| `save_provider` | `(ProviderConfig) -> ProviderConfig` | 保存/更新 Provider |
| `delete_provider` | `(id: String) -> ()` | 删除 Provider |
| `set_active_provider` | `(provider_id: String, model_id: Option<String>) -> ()` | 设为默认 |
| `get_builtin_presets` | `() -> Vec<ProviderConfig>` | 获取内置预设 |

### settings.rs

| 命令 | 签名 | 功能 |
|------|------|------|
| `get_settings` | `() -> AppSettings` | 获取全局设置 |
| `save_settings` | `(AppSettings) -> ()` | 保存全局设置 |

### sync.rs

| 命令 | 签名 | 功能 |
|------|------|------|
| `get_sync_config` | `() -> SyncConfig` | 获取同步配置 |
| `save_sync_config` | `(SyncConfig) -> ()` | 保存同步配置 |
| `test_sync_connection` | `() -> Result<(), String>` | 测试 WebDAV 连接 |
| `trigger_sync` | `(direction: String) -> SyncResult` | 触发同步（upload/download） |

## Services 模块

### ProviderService

```rust
impl ProviderService {
    /// 创建或更新 Provider，校验后写入 SQLite + models.yml
    pub fn save(&self, config: ProviderConfig) -> Result<ProviderConfig, AppError>;
    
    /// 删除 Provider，同时清理 models.yml 中对应节点
    pub fn delete(&self, id: &str) -> Result<(), AppError>;
    
    /// 设置默认 Provider，更新 settings.json
    pub fn set_active(&self, provider_id: &str, model_id: Option<&str>) -> Result<(), AppError>;
    
    /// 获取内置 Provider 预设模板
    pub fn get_presets(&self) -> Vec<ProviderConfig>;
}
```

### ConfigWriter

```rust
impl ConfigWriter {
    /// SQLite → models.yml（原子写入）
    pub fn write_models_yaml(&self) -> Result<(), AppError>;
    
    /// SQLite → settings.json（原子写入）
    pub fn write_settings_json(&self) -> Result<(), AppError>;
    
    /// 合并 Provider 数据为 YAML 结构
    fn build_models_yaml(&self) -> Result<ModelsYaml, AppError>;
}
```

### ConfigReader

```rust
impl ConfigReader {
    /// models.yml → SQLite（启动时回填）
    pub fn read_models_yaml(&self) -> Result<Vec<ProviderConfig>, AppError>;
    
    /// settings.json → SQLite（启动时回填）
    pub fn read_settings_json(&self) -> Result<AppSettings, AppError>;
    
    /// 计算与 SQLite 的差异，仅更新变更部分
    fn compute_diff(&self, file_config: &ProviderConfig, db_config: &ProviderConfig) -> Diff;
}
```

### FileWatcher

```rust
impl FileWatcher {
    /// 启动对 ~/.omp/agent/ 的递归监听
    pub fn start(&self, callback: impl Fn(FileEvent)) -> Result<(), AppError>;
    
    /// 防抖处理（300ms），避免频繁触发
    fn debounce(&self, event: FileEvent) -> Option<FileEvent>;
    
    /// 判断变更是否来自 omp-switch 自身写入（避免循环触发）
    fn is_self_triggered(&self, event: &FileEvent) -> bool;
}
```

### SyncService

```rust
impl SyncService {
    /// 上传本地 db 到 WebDAV
    pub async fn upload(&self) -> Result<SyncResult, AppError>;
    
    /// 从 WebDAV 下载 db 并合并
    pub async fn download(&self) -> Result<SyncResult, AppError>;
```

## 错误处理

统一使用 `thiserror` 定义错误类型：

```rust
#[derive(Error, Debug)]
pub enum AppError {
    #[error("数据库错误: {0}")]
    Database(#[from] rusqlite::Error),
    
    #[error("配置校验错误: {0}")]
    Validation(String),
    
    #[error("文件系统错误: {0}")]
    Fs(#[from] std::io::Error),
    
    #[error("YAML/JSON 解析错误: {0}")]
    Parse(String),
    
    #[error("WebDAV 同步错误: {0}")]
    Sync(String),
    
    #[error("Provider 不存在: {0}")]
    ProviderNotFound(String),
}
```
